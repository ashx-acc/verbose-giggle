Reading the data responsibly

The raw file contains 496 usable rows after pandas skipped one malformed line. 488 of those rows are from 2016, so the year trend is a sample pattern, not a full five-year crime rate. The synthetic_hour column was generated with NumPy seed 42 because the source data has no time-of-day field. Use the dashboard for direction and prioritisation, not for causal claims.
